# Documentation

This directory consolidates the project-specific guides that were previously in the repository root. Use it as the starting point when you need deeper context or environment-specific runbooks.

- `GRAPHQL_SETUP.md` – GraphQL configuration and troubleshooting notes.
- `MIGRATION_INSTRUCTIONS.md` – Database migration checklist and workflows.
- `OLLAMA_PERFORMANCE.md` – Performance tuning for Ollama integrations.
- `VERCEL_MULTIPLE_ACCOUNTS.md` – Deploying across multiple Vercel accounts.
- `WORKFLOW_ANALYSIS.md` – Analysis of the Git working tree process and improvements.
- `test-aws-results.md` – Recorded results from AWS credential validation.
- `test-results/` – Captured output from the end-to-end testing scripts.
